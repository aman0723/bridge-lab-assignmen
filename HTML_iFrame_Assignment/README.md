# HTML iFrame & Form Concepts Assignment

## 📌 Overview
This directory contains solutions for the **HTML iFrames & Forms Assignment** (20 comprehensive practical tasks covering iframes, framesets, head metadata, UTF-8 internationalization, semantic forms, security attributes, entities, and URI encoding).
