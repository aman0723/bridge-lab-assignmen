GRADIENT LAB
Linear Gradient Radial Gradient

1. Linear Gradient & Fixed Attachment

linear-gradient(135deg, #1e3a8a, #065f46)

A linear gradient transitions colors progressively along a straight directional angle (here 135 degrees). This section utilizes background-attachment: fixed to produce a smooth, modern parallax depth illusion when the user scrolls.

2. Radial Gradient Presentation

radial-gradient(circle at center, #701a75, #0f172a)

A radial gradient emanates outwards from a central point or focal coordinate in an elliptical or circular shape. The glow creates a dynamic lighting effect that radiates outwards smoothly towards darker ambient tones.
