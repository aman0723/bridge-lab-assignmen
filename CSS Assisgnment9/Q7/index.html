Responsive Design

Responsive web design allows a webpage to adapt automatically to different screen sizes such as desktops, tablets and mobile devices.

CSS Flexbox, Grid, Media Queries, relative units and responsive images are commonly used to create responsive websites.

CSS Cheat Sheet

Flexbox

display: flex;

Grid

display: grid;

Media Query

@media (max-width: 700px)
