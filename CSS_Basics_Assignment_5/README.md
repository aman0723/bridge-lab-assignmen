# CSS Basics & Layout Mastery (Assignment 5)

## 📌 Overview
This directory contains solutions for **ASSIGNMENT 5 - Submission of CSS Basics** for BridgeLabz Web Development Training.
Each question is implemented in its own modular folder with a separate semantic `index.html` and clean, well-commented `style.css`.
