Question 3

Browser Request & Display Lifecycle

  1. User enters URL: User types web address into the browser navigation bar.
  2. DNS Lookup: Browser resolves the domain name into an IP address.
  3. TCP Handshake & TLS: Secure encrypted communication tunnel is established.
  4. HTTP Request: Browser sends a GET request for the HTML document.
  5. Server Processing: Web server locates resources and sends back 200 OK response.
  6. Rendering Engine (DOM/CSSOM): Browser parses HTML and CSS into the Render Tree and paints pixels.

Question 5

What is a Web Server?

A web server is a software and hardware system that stores, processes, and delivers web pages to clients over the Internet via HTTP/HTTPS.

Commonly Used Web Servers:

  • Nginx: High-performance event-driven reverse proxy and static server.
  • Apache HTTP Server: Modular, highly configurable open-source web server.
  • Node.js / Express: Programmatic microserver for modern RESTful APIs.
  • Microsoft IIS: Enterprise web server designed for Windows Server environments.

Roles in a Software Project

  • Frontend Developer: Builds responsive, accessible UI components from design specifications.
  • Backend Developer: Implements business rules, server logic, database interactions, and secure APIs.
  • Database Administrator (DBA): Maintains database health, schema migrations, query indexes, and disaster backups.

Question 9

Five Web Browsers & Rendering Engines

  • Google Chrome: Powered by the Blink rendering engine and V8 JS engine.
  • Microsoft Edge: Powered by the Blink engine (Chromium based).
  • Mozilla Firefox: Powered by the independent Gecko (Quantum) rendering engine.
  • Apple Safari: Powered by Apple's native WebKit engine.
  • Opera: Powered by the Blink rendering engine.
